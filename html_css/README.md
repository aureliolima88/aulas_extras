# 🌐 Meus Primeiros Passos no Front-End: HTML5 e CSS3

Este repositório foi criado para registrar minha evolução e centralizar os exercícios das minhas aulas extras. Aqui estou aprendendo a construir a base da web, combinando a estruturação de páginas com **HTML5** e a estilização visual com **CSS3**.

---

## 🚀 O que estou aprendendo e praticando:

### 🏗️ Estruturação com HTML5
* **Tags Fundamentais:** Criação da estrutura base de um arquivo web (`<html>`, `<head>`, `<body>`).
* **Organização de Conteúdo:** Uso correto de títulos (`<h1>` a `<h6>`), parágrafos (`<p>`) e listas (`<ul>`, `<li>`).
* **Elementos Visuais e Conectividade:** Inserção de imagens (`<img>`) e criação de links de navegação (`<a>`).

### 🎨 Estilização com CSS3
* **Cores e Fundos:** Aplicação de cores de texto (`color`) e cores de fundo (`background-color`).
* **Modelo de Caixa (Box Model):** Primeiros conceitos de espaçamentos internos (`padding`) e externos (`margin`).
* **Formatação de Texto:** Alteração de tamanho de fontes (`font-size`) e alinhamentos (`text-align`).

---

## 🧠 Desafios de Aprendizado nesta Fase

O foco das sessões de mentoria neste início está em:
1.  **Vincular Arquivos:** Aprender a conectar corretamente o arquivo de estilos (`.css`) dentro do arquivo estrutural (`.html`) usando a tag `<link>`.
2.  **Boas Práticas e Identação:** Manter o código alinhado e organizado para que seja fácil de ler e dar manutenção.
3.  **Visualização em Tempo Real:** Utilizar ferramentas como a extensão *Live Server* do VS Code para ver o resultado do design instantaneamente no navegador.

---
