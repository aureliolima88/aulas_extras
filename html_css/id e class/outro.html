id e class em html (H1)

Em HTML, id serve para identificar um elemento único (deve aparecer apenas uma vez por página), ideal para âncoras ou JavaScript.
O class é usado para agrupar múltiplos elementos que partilham do mesmo estilo ou comportamento, podendo ser reutilizado e combinado livremente.

Principais Diferenças (H2)

Atributo id: (H3)

Unicidade: Cada id só pode existir uma vez por página HTML.Uso no CSS: Selecionado usando o caractere cerquilha/hashtag (#). Exemplo: #cabecalho.Uso no JavaScript: É excelente para manipulação direta de elementos específicos (document.getElementById()).

EXEMPLO
#nome do id
Se o h1 tiver um id com um nome tipo cabecalho (pode colocar qualquer nome) usa-se o # com o nome do id:
h1 id="cor-vermelha"
no style (css) colocará: #cor-vermelha {bacground: red;}

Atributo class: (H3)

Reutilização: Pode ser usado em vários elementos na mesma página.Múltiplas classes: Um elemento pode ter mais de uma classe, separadas por espaço.Uso no CSS: Selecionado com um ponto (.). Exemplo: .botao-azul.

EXEMPLO
.nome da class
Se o h1 tiver uma class com um nome qualquer usa-se o . com o nome da class:
h1 class="cor-vermelha"
no style (css) colocará: .cor-vermelha {bacground: red;}
